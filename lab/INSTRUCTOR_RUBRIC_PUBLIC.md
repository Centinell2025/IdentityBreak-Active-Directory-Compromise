# Public Laboratory Evaluation Rubric

This rubric defines quality expectations without revealing challenge answers.

| Area | Weight |
| --- | ---: |
| Evidence citation and reproducibility | 20% |
| Timeline accuracy and time normalization | 15% |
| Cross-source correlation | 20% |
| Separation of fact / inference / claim | 15% |
| Breach-scope reasoning | 10% |
| Evidence-preserving response | 10% |
| Communication and confidence levels | 10% |

## Senior standard
A passing senior submission should not merely identify suspicious records. It should explain why the records matter, how independent evidence changes confidence, what remains unknown, and which additional evidence would resolve uncertainty.

The private instructor answer key is intentionally not stored in this public repository.
