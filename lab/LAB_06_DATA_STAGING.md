# LAB-06 — Sensitive Data Discovery & Staging

**Role:** Data-breach forensic analyst

## Objective
Determine whether sensitive information was discovered and prepared for transfer.

## Tasks
- Identify the business data categories accessed.
- Correlate server audit, file-system timeline, and collection telemetry.
- Identify the staging artifact and its growth.
- Estimate the observed staged size from supplied evidence.
- Determine whether the archive's deletion destroys all evidence that it existed.
- Separate sensitive-data access from confirmed disclosure.

## Deliverable
Data Staging Worksheet listing source data, timestamps, staging artifact, observed size, supporting event IDs, and confidence.

## Pass criteria
The student can demonstrate staging while explicitly refusing to equate staging with exfiltration.
