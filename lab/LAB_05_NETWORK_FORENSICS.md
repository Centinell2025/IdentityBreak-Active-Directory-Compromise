# LAB-05 — Cisco / Network Forensics

**Role:** Senior network forensic analyst

## Objective
Use DNS, proxy, firewall/flow, VLAN context, and request identifiers to reconstruct relevant communications.

## Tasks
- Establish normal network examples from engineering and automation traffic.
- Identify suspicious internal and external communications.
- Correlate DNS resolutions with firewall sessions.
- Match proxy and firewall records using request IDs.
- Discover and calculate the proxy clock offset.
- Normalize proxy events to canonical UTC.
- Explain what network byte counts can and cannot prove.

## Deliverable
Normalized Network Timeline and a short Network Evidence Assessment.

## Pass criteria
The student discovers the time discrepancy and does not call outbound traffic proof of data theft without additional evidence.
