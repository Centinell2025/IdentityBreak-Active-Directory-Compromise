# LAB-01 — Evidence Intake & Chain of Custody

**Level:** Senior foundation  
**Role:** DFIR evidence custodian

## Scenario
You receive the IdentityBreak evidence package after SOC escalation. Before investigating the incident, establish whether the evidence set can be handled reproducibly.

## Tasks
- Inventory all evidence families.
- Identify source system, collection time, time reference, and known limitation for each family.
- Build an evidence register.
- Identify which sources would require cryptographic hashing after the evidence set is frozen.
- Identify missing volatile and external evidence.
- Define a chain-of-custody workflow for a real enterprise investigation.

## Deliverable
Create a one-page Evidence Intake Report containing: evidence ID, source, collection method, integrity status, time basis, limitation, and preservation priority.

## Pass criteria
The student distinguishes evidence integrity from evidentiary completeness and does not begin attribution before documenting collection limitations.
