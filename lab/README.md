# IdentityBreak — Senior DFIR Laboratory Track

These laboratories turn the Sherlock evidence set into a structured technical training path.

## Training scope

All exercises use fictional identities, synthetic evidence, documentation IP ranges, disposable files, and authorized isolated lab systems. Students do not need to execute malware, steal credentials, exploit third-party systems, or reproduce destructive behavior.

## Laboratory sequence

1. LAB-01 — Evidence Intake & Chain of Custody
2. LAB-02 — Windows Endpoint Triage
3. LAB-03 — Active Directory Identity Investigation
4. LAB-04 — Lateral Movement Reconstruction
5. LAB-05 — Cisco / Network Forensics
6. LAB-06 — Sensitive Data Discovery & Staging
7. LAB-07 — Exfiltration Assessment
8. LAB-08 — Selective Encryption Forensics
9. LAB-09 — Anti-Forensics & Timeline Recovery
10. LAB-10 — Breach Scope & Senior Incident Response

Each laboratory requires evidence citations and a short analyst deliverable. The objective is not to guess the scenario narrative but to make defensible findings from evidence.
