# LAB-08 — Selective Encryption Forensics

**Role:** Digital forensic engineer

## Objective
Investigate a simulated selective encryption event without running ransomware.

## Tasks
- Establish the first supported encryption-related timestamp.
- Correlate file-system changes with encryption telemetry.
- Compare original/result sizes and entropy observations.
- Identify affected business datasets.
- Explain why an extension change alone would be insufficient.
- Propose safe evidence collection from an affected server before recovery.
- Design a clean recovery verification checklist.

## Deliverable
Encryption Impact Report and recovery evidence checklist.

## Pass criteria
The student uses multiple forensic indicators and proposes preservation before restoration.

**Safety:** no executable ransomware is provided or required.
