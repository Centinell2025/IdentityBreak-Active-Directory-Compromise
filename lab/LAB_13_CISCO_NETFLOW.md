# LAB-13 — Cisco / NetFlow Correlation

**Role:** Senior network forensic analyst

## Objective
Correlate Cisco-ASA-like logs, NetFlow-like records, DNS, proxy, and firewall summaries.

## Tasks
- Map internal source IPs to assets and VLANs.
- Separate ordinary engineering/automation flows from incident-relevant traffic.
- Correlate connection IDs/request IDs where possible.
- Reconstruct internal movement and external communication chronologically.
- Calculate the proxy clock offset using matched events.
- Explain differences between session establishment, flow volume, application response status, and proof of content disclosure.

## Deliverable
Network Correlation Matrix and normalized UTC timeline.

## Pass criteria
No network artifact is treated as proof of stolen file content without corroborating evidence.
