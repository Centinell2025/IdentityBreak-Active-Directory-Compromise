# LAB-03 — Active Directory Identity Investigation

**Role:** Senior identity / AD forensic analyst

## Objective
Analyze privileged identity use and directory modifications.

## Tasks
- Establish the normal administrative source for aortiz.
- Compare approved ADMIN-01 activity with later authentication from WIN-FIN-04.
- Interpret failed and successful authentication records.
- Analyze Remote-Support and Job-Review-Temp group operations.
- Determine which changes were reversed and which created a continuing access path.
- Build a hypothesis for identity misuse without assuming how credentials were obtained.

## Deliverable
Identity Compromise Assessment with normal baseline, anomalous source, directory changes, affected identities, confidence, and recommended identity containment.

## Pass criteria
The student never equates the account name with the person and does not invent a credential-theft mechanism absent from evidence.
