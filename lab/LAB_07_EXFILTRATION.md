# LAB-07 — Exfiltration Assessment

**Role:** Senior breach investigator

## Objective
Answer the management question: **Was data actually stolen?**

## Tasks
- Correlate the staging window with DNS, proxy, and firewall sessions.
- Normalize the proxy timestamps before comparing them.
- Compare staged bytes with observed outbound byte counts.
- Interpret HTTP success/reset observations carefully.
- Review the stated evidence gaps, including absent request bodies and external server logs.
- Classify the conclusion as confirmed exfiltration, probable transfer, attempted transfer, suspicious communication, or insufficient evidence.
- State what additional evidence would materially increase confidence.

## Deliverable
A two-part assessment: **Technical Finding** and **Executive Finding**, each with confidence.

## Pass criteria
The conclusion must be no stronger than the evidence permits. The extortion note cannot be used as independent proof.
